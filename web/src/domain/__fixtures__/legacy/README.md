# Старі відповіді (лютий 2026)

`slots.json` і `slots_not_working.json` — відповіді розкладу e-Consul, записані у лютому 2026
для старого `slots.html`. Моменту запису в них немає, тому їх не можна використовувати в
тестах із фіксованим `nowMs`. Лише для ручних порівнянь. Записані відповіді для тестів — у
[`../econsul/`](../econsul/).
