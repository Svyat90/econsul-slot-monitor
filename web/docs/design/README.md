# Дизайн застосунку

Макет нового застосунку (модуль `web/`), узгоджений у брейнштормі 2026-10-09
([IDEA-001…003](../../../docs/brainstorm/ideas.md)). Стиль — дизайн A розширення
([extension/docs/design](../../../extension/docs/design/README.md)).

Полотно в Claude Design (приватне, відкривається з облікового запису власника):
https://claude.ai/artifact/KMPRopJoyDxFFtxJFomEDX

## Екрани

| Екран | Знімок |
|---|---|
| Слоти: наступне відкриття, найближчі вільні, календар, панель дня | [slots.png](slots.png) |
| Моніторинг: зведення за день, журнал перевірок з фільтрами, журнал резервувань, зміни розкладу | [monitoring.png](monitoring.png) |

Знімки — еталон для перевірки реалізації: розкладка, тексти, кольори. Дані на них вигадані
(Чикаго, сьогодні 09.10.2026, межа горизонту 01.04.2027).

## Файли

| Файл | Що це |
|---|---|
| `Main.dc.html` | Вихідний макет у форматі Claude Design: увесь застосунок, інтерактивний (меню, календар, фільтри) |
| `Monitoring.dc.html`, `Settings.dc.html` | Той самий макет, відкритий на іншому розділі (`<dc-import name="Main" section="…">`) |
| `canvas.json` | Розкладка полотна |
| `*.png` | Знімки екранів |

`.dc.html` відкриваються лише на полотні (потрібен рантайм Claude Design). Перемикачі на полотні
(Tweaks): `scenario` — звичайний / сесія скінчилась / нові слоти / установу не вибрано;
`section` — розділ; `extension` — розширення підключене чи ні; `accent` — колір дій.
