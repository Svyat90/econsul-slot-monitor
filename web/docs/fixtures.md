# Фікстури відповідей e-Consul

Записані відповіді API — основа тестів домену (`web/src/domain/`): алгоритм вільних слотів, горизонт,
моменти відкриття днів. Тести не ходять на сайт; вони беруть відповідь із файлу і фіксований
`nowMs` — момент запису.

## Як записати

1. Увійдіть на https://e-consul.gov.ua у Chrome.
2. DevTools › Console, вставте вміст [`web/scripts/record-econsul-fixtures.js`](../scripts/record-econsul-fixtures.js),
   Enter. Chrome може спитати дозвіл на завантаження кількох файлів — дозвольте.
3. Скрипт по черзі для Чикаго, Г'юстона й Нью-Йорка (послуга 1 — закордонний паспорт) робить
   **ті самі два запити, що й моніторинг**: розклад і зайняті слоти, з паузою 2 с. Нічого не
   бронює, у файли не пише токен.
4. Перенесіть файли `chicago-YYYY-MM-DD.json`, `houston-…`, `new-york-…` з «Завантажень» у
   `web/src/domain/__fixtures__/econsul/`.

Перед комітом переконайтеся, що у файлах немає токена:
`grep -l '"token"' web/src/domain/__fixtures__/econsul/*.json` нічого не має знайти.

## Формат файлу

| Поле | Що це |
|---|---|
| `recordedAt`, `recordedAtMs` | Момент запису — `nowMs` для тестів горизонту й відкриття днів |
| `institutionCode`, `serviceCode` | Установа й послуга |
| `requests` | Метод і фільтри обох запитів (без токена) |
| `schedule` | Відповідь `public-calendar-get-actual-consuls-schedule` як є |
| `reserved` | Відповідь `public-get-consuls-reserved-slots` як є (`null`, якщо послугу ніхто не надає) |

Параметри установи (часовий пояс, горизонт, тривалість слоту, свята) тести беруть з
`locations.json`.

## Що робити з файлами

- Звірка зі `slots.html` (етап 3 [плану](../../docs/plans/web-rewrite-plan.md)):
  `pnpm --dir web run reconcile` — відкриває `slots.html` з робочого сервера в окремому headless
  Chrome і порівнює дні, вільні слоти й моменти відкриття з новим доменом на кожній фікстурі, на
  шести моментах часу й трьох варіантах зайнятих слотів (записані, кожен другий, жодного). Запитів до
  e-Consul немає. Потрібні запущений сервер і встановлений Google Chrome.
- Записи 2026-10-09 мають **0 вільних слотів** (усі дні зайняті), тому тести вільних слотів беруть
  ті самі відповіді з частиною зайнятих слотів прибраною. Новий запис з вільними слотами корисний,
  коли вони з'являться.
- Старі `slots.json` і `slots_not_working.json` — відповіді лютого 2026 без моменту запису;
  лежать у `src/domain/__fixtures__/legacy/` лише для ручних порівнянь, тести їх не беруть.
- Нові записи — коли сайт змінює формат відповіді або для нового класу випадків (свята, кілька
  проміжків прийому на день, перехід на зимовий час).
