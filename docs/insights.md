# Інсайти

Замітки про неочевидну поведінку браузера, сайту й інструментів, на яку ми натрапили під час роботи.
Нові замітки — зверху розділу, з датою.

## Розширення Chrome

### Після змін у коді розширення треба натиснути ⟳ у `chrome://extensions` (2026-10-08)

Розпаковане розширення Chrome бере з диска **по-різному**:

| Частина | Коли підхоплює зміни |
|---|---|
| `popup.html/.js/.css`, `offscreen.html` | Щоразу, коли сторінку відкривають |
| `background.js` (service worker), content scripts (`econsul.js`, `app-bridge.js`), `manifest.json` | **Лише після перезавантаження розширення** (⟳ на картці в `chrome://extensions`) |

Перезавантаження вкладок e-consul чи `localhost:3000` **не** оновлює content scripts.

Як це виглядало: попап уже новий («Передаю токен у застосунок…», «Створити нову»), а чернетка з
відкритої вкладки не підхоплюється і «токен передано» не з'являється — працювали старі background
і `econsul.js`, у яких цього ще не було. Після ⟳ усе запрацювало.

Що зроблено: попап порівнює версію з `manifest.json` на диску із завантаженою
(`chrome.runtime.getManifest()`) і показує плашку «Код розширення оновлено. Натисніть ⟳…».
**Тому при кожній зміні background чи content scripts піднімайте `version` у `manifest.json`.**
Після ⟳ background сам додає content scripts у вже відкриті вкладки (`onInstalled` →
`chrome.scripting.executeScript`), вкладки можна не перезавантажувати.

### Сайт записує токен через кілька секунд після завантаження сторінки (2026-10-08)

Після повернення з входу (`id.e-consul.gov.ua`) `localStorage.token` з'являється не одразу, а за кілька
секунд. Подія `storage` у тій самій вкладці не спрацьовує. Перевірка токена раз на хвилину давала
затримку до хвилини, а перевірка одразу на завантаженні — хибне «немає токена» з тривогою.
Тому `econsul.js` читає токен кожні 2 с, а «немає токена» зараховує лише після 10 с без нього.

### `hidden` не ховає елемент із власним `display` (2026-10-08)

`.ext-banner { display: flex }` перекриває атрибут `hidden` (у браузера це лише
`[hidden] { display: none }` з найнижчим пріоритетом). Банер «Увійдіть» не зникав. Потрібне явне
`.ext-banner[hidden] { display: none; }` (у попапі — `[hidden] { display: none !important; }`).

### Звук в offscreen-документі грає без кліку (2026-10-08)

`AudioContext` в offscreen-документі з причиною `AUDIO_PLAYBACK` одразу в стані `running`, без жесту
користувача. На сторінці застосунку — ні: там звук можливий лише після кліку на сторінці, тому
застосунок повідомляє `audioReady`, і background вирішує, хто грає звук.

## Тестування

### Як запускати розширення в Chrome для автотестів (2026-10-08)

- Брендований Google Chrome (154) не підтримує `--load-extension`. Працює puppeteer 24 з системним
  Chrome: `puppeteer.launch({ executablePath: '/Applications/Google Chrome.app/…', pipe: true,
  enableExtensions: [path] })` — розширення ставиться через CDP. Chrome for Testing від puppeteer
  на цьому Mac розпаковувався неповністю (немає Framework), тому він не підходить.
- Сервер на порту 3000 може належати іншій сесії (`gov-server`): він віддає `slots.html` прямо з
  диска, тож зміни видно в ньому одразу. Для тестів — `python3 -m http.server 3001` і копія
  розширення, де `localhost:3000` замінено на `3001`. `POST /schedule-log` там дає 501 — це очікувано.
  Go в системі не встановлено.
- e-consul, `auth/me`, `GET /tasks/{id}` — заглушки через `page.setRequestInterception`; для
  `my.e-consul.gov.ua` треба відповідати й на CORS preflight (`OPTIONS`, заголовок `token`).
  `callExternalReader` у застосунку підміняється з `page.evaluate`.
- У headless puppeteer `page.click()` у фоновій вкладці зависає (чекає на прокрутку). Клікати через
  `page.$eval(sel, el => el.click())` або спершу `bringToFront()`.
- Сторінка попапу у вкладці (`chrome-extension://<id>/popup.html`) має `sender.tab`, на відміну від
  справжнього попапу: перевіряти відправника за `sender.url`, а не за відсутністю вкладки.

### Claude in Chrome (2026-10-08)

Після `/chrome` інструменти `mcp__claude-in-chrome__*` у вже запущену сесію Claude Code не
з'явилися. Імовірно, потрібен перезапуск Claude Code. Без них етап 0 (дослідження форми на живій
сесії) не зробити.
