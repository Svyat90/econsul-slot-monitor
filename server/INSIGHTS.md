# Інсайти server/

Неочевидна поведінка сервера, його інструментів і бази. Нові замітки — зверху розділу, з датою.
Веде скіл `engineering-insights`. Спільне для кількох модулів — у [../INSIGHTS.md](../INSIGHTS.md).

## Знімки календаря (2026-10-16)

`calendar_snapshots` зберігає лише зміни: клієнт шле знімок, коли хеш розкладу чи зайнятих слотів
інший, ніж він надсилав останнім, а сервер ще й пропускає точний повтор найновішого знімка тієї
самої установи й послуги (без `UPDATE`, тож «востаннє бачили» окремо не оновлюється — свіжість
береться з `monitor_checks`: `lastCheckAt`). Зайняті слоти пишуться стисло (`consuls` + трійки
`[індекс, від, до]`): сирі відповіді — ~550 КБ, тіло POST обмежене 1 МБ, тому в черзі застосунку знімки
йдуть по три й тримаються лише п'ять найновіших, поки сервер недоступний. Рядки розкладу — публічні
дані сайту (хеші консулів, години, послуги); ключі, схожі на токен, відхиляються.

## Інструменти

### TypeScript 7 не підходить для лінтерів (2026-10-09)

`typescript@7` (нативний компілятор) ще не має JS API. Через це `dependency-cruiser` з
`tsPreCompilationDeps` пише «Install typescript to get better results (npm i -D typescript@^6)»,
а `typescript-eslint` не працює. Правило: `typescript@^6` в обох модулях, доки TS 7 не опублікує API.

### pnpm 12 відмовляє в свіжих релізах (2026-10-09)

pnpm має мінімальний вік релізу. На пакет, опублікований того ж дня (`@fastify/static@10.1.6`),
він дописує виняток `minimumReleaseAgeExclude` у `pnpm-workspace.yaml`. Правило: такий виняток не
комітити, а брати попередню версію (`~10.1.5`). Скрипти збірки дозволяються там само:
`allowBuilds: { esbuild: true }` (потрібен для `drizzle-kit`).

## Сервер

### Зупинений Postgres дає 503 на всі `/api/*` (2026-10-14)

Сервер на `:3000` лишається живим, коли контейнер `server-postgres-1` зупинено (`Exited (0)`,
наприклад після виходу з Docker Desktop: `restart: unless-stopped` не підіймає вручну зупинений
контейнер). Вебзастосунок тоді показує «Не вдалося завантажити…», а в Network — 503 на
`summary`, `checks`, `schedule-log` тощо. Діагноз: `curl localhost:3000/api/health` →
`{"status":"degraded","db":"down"}`. Лікування: `pnpm run db:up` (не `down -v`).

### `@fastify/static` не на корінь репозиторію (2026-10-09)

У корені репозиторію лежать `logs/` і `.git` (а до 2026-10-21 — `slots.html`). Статика з `root: repoRoot`
віддала б їх усім. Правило: довідник — окремим маршрутом, що читає фіксований файл;
`@fastify/static` — лише на `web/dist`.

### Тести не пишуть у робочий журнал (2026-10-09)

Записи вічні, тож тестовий рядок у базі `econsul` лишився б назавжди. Правило: `*.it.test.ts`
працюють лише з базою `econsul_test` (`createTestDb()`); перевіряти маршрути вручну — без POST у
робочий сервер, або на іншому порту з `DATABASE_URL` тестової бази.
