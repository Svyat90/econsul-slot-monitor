# Інсайти

Замітки про неочевидну поведінку браузера, сайту й інструментів, яка стосується кількох модулів.
Інсайти окремого модуля — у `<модуль>/INSIGHTS.md`
(розширення: [extension/INSIGHTS.md](extension/INSIGHTS.md)).
Нові замітки — зверху розділу, з датою. Веде скіл `engineering-insights`.

## Тестування

### Записані відповіді без вільних слотів (2026-10-09)

Фікстури Чикаго, Г'юстона й Нью-Йорка, записані 2026-10-09, дають 0 вільних слотів: усі відкриті
дні зайняті. Звірка й тести лише на них порівнюють порожні результати. Правило: перевіряти алгоритм
ще й на тих самих відповідях без частини зайнятих слотів (так робила звірка зі `slots.html`, видалена 2026-10-21) і на моменті
після відкриття нового дня (+26 год від запису — з'являються 18–24 вільні слоти).

### Звірка з `slots.html` у браузері (2026-10-09)

Функції й змінні `slots.html` — глобальні лексичні прив'язки класичного скрипта (`let`), а не
властивості `window`. З `page.evaluate` до них дістається `window.eval('ім'я')`; присвоєння —
`eval('releaseCache = null')`. `Date.now` треба підміняти до виклику `calculateBookableWindows()`:
вона викликає `buildScheduleDays()` без аргументу.

Оновлено 2026-10-21: `slots.html` і скрипт звірки видалено (S8.T5) — запис лишається як історія.

### Запис фікстур через Claude in Chrome: друге завантаження блокується мовчки (2026-10-09)

`web/scripts/record-econsul-fixtures.js`, запущений через `javascript_tool`, завантажив лише
перший файл (Чикаго). Решту Chrome заблокував без видимого діалогу, і перезавантаження сторінки
цього не скинуло. Допомогло, коли користувач сам дозволив e-consul.gov.ua автоматичне
завантаження кількох файлів (значок в адресному рядку або
`chrome://settings/content/automaticDownloads`). Правило: перед записом попросити користувача дати
цей дозвіл. Після запуску перевіряти `~/Downloads`, а не вірити виводу скрипта.

Коли розширення не підключене, `list_connected_browsers` повертає `[]`. Це швидка перевірка
перед повторними спробами.

### Claude in Chrome (2026-10-08, оновлено 2026-10-09)

Після `/chrome` інструменти `mcp__claude-in-chrome__*` у вже запущену сесію Claude Code не
з'явилися. 2026-10-09 вони запрацювали, щойно користувач увійшов у розширення Claude у Chrome.
Claude бачить і керує лише вкладками своєї групи, а не вкладками користувача. Тому чернетку
відкривав за адресою з `localStorage` застосунку (`slots.draft`).

## Інструменти

### Системний `python3` без PyYAML — frontmatter перевіряти через Ruby (2026-10-09)

`python3 -c "import yaml"` на цьому Mac падає з `ModuleNotFoundError: No module named 'yaml'`, а
`pip install` змінює системне середовище. Ruby зі стандартною бібліотекою YAML є.

Правило: перевіряти frontmatter скілів і агентів так:
`ruby -ryaml -e 's=File.read(ARGV[0]); YAML.safe_load(s[/\A---\n(.*?)\n---/m,1])' <file>` — для
кожного `.claude/skills/*/SKILL.md` (і `.claude/agents/*.md`, якщо агенти знову з'являться локально) після правок опису (`description` з
двокрапкою чи лапками легко ламає YAML).
