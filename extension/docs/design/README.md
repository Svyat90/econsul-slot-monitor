## Як відкрити

- **У браузері:** `design-a.html`. Потрібен інтернет лише для шрифтів Google Fonts (Manrope,
  IBM Plex Mono); без нього підставляться системні.
- **На полотні:** за посиланням вище — там макет можна змінювати.

`Main.dc.html` напряму в браузері не відмалюється: шаблони `{{…}}`, `<sc-for>`, `<sc-if>` виконує
рушій `support.js`, який є лише на полотні.

### Як оновити після правок на полотні

1. Завантажити `project/Main.dc.html` з полотна і покласти замість `Main.dc.html` тут.
2. `python3 extension/docs/design/build.py` — перезбирає `design-a.html`.
3. Відкрити `design-a.html`, порівняти з полотном, оновити `preview.png` і таблицю нижче, якщо
   змінились кольори чи розміри.

Якщо в макеті з'явиться новий шаблон (`{{…}}` чи `<sc-…>`), скрипт зупиниться й назве його.
